개인정보처리방침

최종 업데이트: 2026년 6월 15일 · 시행일: 2026년 6월 15일

NOMAD AI(이하 "앱")는 이용자의 개인정보를 소중하게 다루며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 개인정보처리방침은 앱이 이용자의 정보를 어떻게 수집, 이용, 저장, 보호하는지 안내합니다.

핵심 요약: NOMAD AI 는 안드로이드 온디바이스 LLM 앱으로, 대부분의 처리가 이용자의 기기 내부에서 이루어집니다. 대화 내용, 이미지 입력, 음성 입력, TTS 입력 텍스트, 생성 음성은 원칙적으로 외부 서버로 전송되지 않습니다. 다만 이용자가 AI 답변을 신고하는 경우, 신고 처리를 위해 신고 대상 AI 답변과 신고 정보가 Supabase Storage 로 전송·보관될 수 있습니다.

1. 수집하는 개인정보 항목

NOMAD AI 는 회원가입, 로그인, 계정 식별 없이 사용 가능한 앱이며, 일반 기능에서는 이용자로부터 개인 식별 정보를 직접 수집하지 않습니다. 다만, 앱의 기능 제공을 위해 아래와 같은 데이터가 기기 내부에서 처리됩니다. 신고 기능을 이용하는 경우에는 신고 처리에 필요한 일부 데이터가 외부 서버로 전송되며, 이용자가 신고 사유에 직접 입력한 내용도 함께 전송됩니다.

항목 처리 위치 목적 보관 기간
대화(채팅) 기록 기기 내부 저장소 대화 이어가기, 기능 제공 이용자가 삭제하거나 앱을 삭제할 때까지
이미지 입력 기기 내부 메모리 이미지 내용 이해, 텍스트 인식 및 AI 대화 보조 처리 즉시 메모리에서 소멸(저장되지 않음)
마이크 음성 입력 기기 내부 메모리 음성 인식(STT)을 통한 대화 입력 처리 즉시 메모리에서 소멸(저장되지 않음)
TTS 입력 텍스트 및 생성 음성 기기 내부 메모리 텍스트 음성 변환(TTS) 및 음성 안내 기능 제공 처리 즉시 메모리에서 소멸(저장되지 않음)
앱 설정(언어, 모델 선택 등) 기기 내부 저장소 사용자 환경 유지 앱 삭제 시까지
네트워크 요청 로그 일시적(휘발성) AI 및 TTS 모델 다운로드 요청 종료 시 삭제
신고 데이터(AI 답변 내용, 신고 사유, locale, 생성 시각, 신고 파일 저장 정보) Supabase Storage 부적절하거나 오류가 있는 AI 답변 신고 접수, 검토 및 서비스 품질 개선 신고 검토 완료 후 삭제하며, 최대 1년 이내 보관

수집하지 않는 정보

아래 정보는 일반 기능에서 별도로 요구하거나 수집하지 않습니다. 단, 이용자가 신고 사유에 임의로 입력한 개인정보는 신고 데이터에 포함되어 전송될 수 있으므로 민감한 개인정보를 입력하지 않는 것이 좋습니다.

  • 이름, 전화번호, 이메일, 주소 등 개인 식별 정보
  • 주민등록번호 등 고유 식별 정보
  • 계정 정보, 비밀번호
  • 위치 정보(GPS)
  • 연락처, 통화 기록, SMS
  • 광고 식별자(ADID) 및 기기 지문

2. 개인정보의 수집 및 이용 목적

  • 오프라인 AI 대화 기능 제공
  • 음성 입력(STT)을 통한 대화 입력 기능 제공
  • 텍스트 음성 변환(TTS) 및 음성 안내 기능 제공
  • 이미지 입력 기반 텍스트·내용 이해 기능 제공
  • 번역, 요약, 작성 보조 등 언어 처리 기능 제공
  • AI 답변 신고 접수, 검토, 오류 분석 및 서비스 품질 개선
  • 이용자 환경 및 선호도 유지(앱 설정)

3. 개인정보의 처리 및 보관

NOMAD AI 는 이용자의 대화, 이미지, 음성 입력, TTS 입력 텍스트, 생성 음성을 원칙적으로 당사 서버나 제3자 서버로 전송하지 않습니다. 일반적인 앱 기능 처리는 이용자의 기기 내부에서 이루어지며, 기기 저장소에만 보관됩니다.

  • 데이터 보관 위치: 이용자의 Android 기기 내부 저장소
  • 서버 보관: 일반 기능 데이터는 서버에 보관하지 않으며, 신고 기능을 이용하는 경우 신고 데이터가 Supabase Storage 에 보관됩니다.
  • 신고 데이터 보관: 신고 검토 및 오류 분석에 필요한 기간 동안 보관한 뒤 삭제하며, 특별한 사정이 없는 한 수집일로부터 최대 1년을 넘기지 않습니다.
  • 자동 삭제: 앱 삭제 시 기기에 저장된 데이터도 모두 함께 삭제됩니다.

4. 외부 전송 및 제3자 제공

앱은 원칙적으로 이용자의 개인정보를 외부로 전송하거나 제3자에게 제공하지 않습니다. 다만, 다음 기능에 한해 최소한의 네트워크 요청이 발생합니다.

요청 대상 전송 정보 목적
AI 모델 배포 서버(예: Hugging Face) 모델 파일 요청 URL, 기기의 IP 주소 Gemma 및 TTS 모델 파일 다운로드
Supabase Storage 신고 대상 AI 답변 내용, 이용자가 입력한 신고 사유, locale, 생성 시각, 신고 파일 저장 정보 AI 답변 신고 접수, 검토, 오류 분석 및 서비스 품질 개선

위 통신은 표준 HTTPS 를 사용합니다. 모델 다운로드 요청에는 이용자의 대화·이미지·음성 입력·TTS 입력 텍스트·생성 음성이 포함되지 않습니다. 신고 기능을 이용하는 경우에 한해 신고 대상 AI 답변과 신고 사유 등 신고 처리에 필요한 정보가 Supabase Storage 로 전송됩니다.

신고 데이터의 제3자 처리

신고 데이터는 저장·관리 인프라 제공자인 Supabase 를 통해 보관될 수 있습니다. Supabase 는 NOMAD AI 의 신고 접수 및 검토 목적을 위한 처리자로 사용되며, NOMAD AI 는 신고 데이터를 광고, 추적, 판매 목적으로 제공하지 않습니다.

5. 이용자의 권리와 행사 방법

이용자는 언제든지 다음과 같은 권리를 행사할 수 있습니다.

  • 열람·수정·삭제: 앱 내 "설정 > 데이터 관리" 에서 저장된 대화 기록을 확인·삭제할 수 있습니다.
  • 전체 삭제: 앱을 기기에서 제거하면 모든 데이터가 즉시 삭제됩니다.
  • 신고 데이터 삭제 요청: 이미 전송된 신고 데이터는 앱 삭제만으로 Supabase Storage 에서 자동 삭제되지 않을 수 있습니다. 삭제를 원하는 경우 아래 문의처로 요청할 수 있으며, 신고 검토 또는 법령상 보관이 필요한 경우를 제외하고 지체 없이 삭제합니다.
  • 권한 거부·철회: Android 시스템 설정에서 카메라·마이크 등 앱 권한을 언제든지 허용/거부할 수 있습니다.

6. 앱 권한 안내

권한 필수/선택 사용 목적
인터넷(INTERNET) 필수 AI 및 TTS 모델 다운로드, 신고 데이터 전송
카메라(CAMERA) 선택 이미지 입력 및 AI 대화 보조
마이크(RECORD_AUDIO) 선택 음성 인식(STT)을 통한 대화 입력
저장소(READ/WRITE_MEDIA_IMAGES) 선택 갤러리에서 이미지 선택
네트워크 상태 확인(ACCESS_NETWORK_STATE) 필수 오프라인 여부 확인 및 오류 안내

7. 만 14세 미만 아동의 개인정보

앱은 별도의 회원가입이나 개인정보 수집 기능이 없어 만 14세 미만 아동을 식별하거나 타깃팅하지 않습니다. 보호자는 자녀의 앱 사용 및 권한 허용 여부를 확인해 주시기 바랍니다.

8. 개인정보의 안전성 확보 조치

  • 네트워크 구간 TLS/HTTPS 암호화
  • 일반 기능 데이터는 기기 내부 저장소에 한정하여 보관
  • 신고 데이터는 Supabase Storage 접근 권한을 제한하여 관리
  • 불필요한 로그 및 식별자 미수집
  • 외부 추적·광고 SDK 미포함

9. 개인정보처리방침의 변경

본 방침은 법령 및 앱 기능 변경에 따라 개정될 수 있습니다. 중요한 변경이 있을 경우 앱 내 공지 또는 본 페이지를 통해 최소 7일 이전에 안내드립니다.
